# Assets

Add your own screenshots, architecture diagrams, and demo recordings
here for the hackathon submission, e.g.:

```
assets/
├── screenshots/   PNG/JPG captures of each of the 8 app screens
├── diagrams/      Exported versions of the architecture diagram (docs/architecture.md has the ASCII source)
└── demo/          Screen recording of the judge demo script (docs/demo.md)
```

Nothing is bundled here by default to keep the repository lightweight —
this file exists so the folder isn't empty/meaningless in git, and so
contributors know what belongs here.
